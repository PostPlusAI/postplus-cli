# Thumbnail concepts

Choose a concept that raises a question the actual video answers. Use the user's
existing direction when clear; explore alternatives only when useful, without a
fixed minimum number or compulsory batch generation.

| Framework | Use it to depict |
| --- | --- |
| Before/after | Two clearly comparable states of the same subject |
| Social UI | A generic conversation/review motif tied to real content; never fabricate testimony |
| Three-step progression | Start, meaningful intermediate state and outcome |
| Compelling source frame | A real frame from the supplied video; a generated scene is not a screenshot |
| Posed portrait | One large expressive face with a simple supporting environment |
| Action moment | One intriguing action caught at a legible instant |
| Specific day | A truthful time milestone central to the story |
| Graphic explanation | A simple diagram or chart appropriate to the content |
| Landscape | The environment as hero, with a small subject for scale |
| Map or aerial | A route, location or spatial relationship |
| Product | The product as the answer to the video's central question |
| Text and image | A short readable phrase that complements rather than repeats the title |
| Repeated objects | Many copies of one object plus a clear scale/context cue |
| Size contrast | Large versus small elements meaningful to the story |
| News-style frame | Generic editorial framing without fake reporting or broadcaster endorsement |
| Amplified reality | One exaggerated real story element, without misrepresenting the content |

Combine frameworks only when the concept stays clear. Preserve approved identities
and product attributes. Treat labels and typography as an output requirement to
verify; neither generated text nor an unimplemented overlay pipeline is assumed
reliable. Real logos and quotes need the appropriate supplied context.

Check one clear focal subject, a meaningful information gap, contrast, readability
at roughly 120px, and a concept that reads quickly in a feed. Faces should express
an emotion relevant to the content. Avoid clutter and misleading before/after,
numbers, testimonials or news implications. These are creative heuristics, not
measured guarantees of click-through or advertising conversion.

# Reuse Project Facts

Read this when repeated creative work needs consistent brand, product or persona
facts. Reuse the user's existing brief and files; do not require a new document
system for a one-off task.

For an ongoing project, `postplus-workspace` owns workspace setup. Its brand,
product, persona and hook files can preserve agreed facts and creative choices.
Read only the facts needed for the task, and distinguish approved claims from
ideas or unvalidated hooks. Update them only within the user's requested scope.

Explain the benefit as consistent work, not mandatory paperwork. Do not create a
parallel set of project facts in each skill or treat a saved statement as evidence
of performance.

# Media Skill View

`generate` owns image creation/editing, video generation and spoken voice takes,
from request interpretation through execution and actual media delivery. It reads
only the relevant local references. New models extend the PostPlus capability
schema rather than introducing another planning or submission Skill.

`ad-creative` owns advertising direction, proof and shot scripts. Eight advertising
methods remain available as references under one shared workflow. An approved script
goes directly to generation; a simple media request needs no advertising brief.

`media-analysis` owns media understanding and an optional creative reference
breakdown. Ordinary analysis does not automatically enter creative planning.

Endpoint fields, input roles, enums and defaults come from `postplus media schema
--json`. See [reference guidance](reference-registry.md) for the distinction between
binding assets and inspiration. No intermediate architecture JSON or second brief
is required. A run handle is not finished media, and loose clips are not an assembled
film. Dedicated film assembly and synchronized translation dubbing are not implied.
